# Decisiones

> Escribe el líder (`integration-architect`). Una entrada por decisión con alternativas reales. Los cambios de alcance de `requirements.json` también van aquí y requieren aprobación del usuario.

## Formato

```
## D-00X — <título> (<YYYY-MM-DD>)
**Contexto:** <requisito(s) afectados>
**Opciones:** <A / B / C con tradeoffs>
**Evidencia:** <fuente · VERIFIED | COMMUNITY | UNVERIFIED>
**Decidió:** <usuario | líder con aprobación>
**Decisión:** <qué y por qué>
```
